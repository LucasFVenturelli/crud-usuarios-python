# CRUD de Usuários em Python

Este projeto implementa um CRUD de usuários utilizando apenas Python e listas em memória.  
Permite criar, listar, buscar e deletar usuários com base no CPF.  
Cada usuário possui nome, email, senha e CPF como campos obrigatórios.  
A lógica está separada em módulos para facilitar manutenção e testes.  
Os testes são feitos com `unittest` e cobrem todos os casos principais.  
Não é necessário banco de dados, tudo roda localmente.  
Interface simples via terminal no `main.py`.  
Os dados não são salvos após encerrar o programa.  
CI com GitHub Actions executa os testes a cada push.  
Ideal para praticar lógica de programação e testes automatizados.
